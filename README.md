# Farming-Tools-App
A web application that allows users to rent or buy farming tools with a user-friendly interface.

Features
✅ Browse farming tools
✅ Search for specific tools
✅ Rent tools on a weekly basis
✅ Buy tools directly
✅ Cart functionality
✅ Authentication & Logout

Tech Stack 🛠️
Frontend (Client)
React.js
React Router
CSS (with responsive design)
Backend (Server)
Node.js
Express.js
MongoDB (Database)
JWT (Authentication)
